# BY KEY

**鸿蒙手机端**蓝牙数字钥匙 App —— 让手机当车钥匙，靠近解锁、远离上锁。旧名 BydNearKey。

> **这是装在手机上的应用，不是手表应用。** 蓝牙无感解锁、云端控车、车况查看全部由手机完成，
> 手表可以不参与。之所以名字里带「手表」，是因为它沿用官方**手表钥匙**的独立授权通道
> （应用内出码、官方 App 扫码确认），这样能与官方手机 App 同时在线、互不顶号。

**本仓库只分发安装包，不含源码。** 下载与历史版本见 [Releases](../../releases)。

## 主要功能

1. **熄屏靠近解锁、远离上锁** —— 走近自动解锁，走远自动落锁，优先蓝牙直连，连不上自动回落云端兜底。
2. **老车主也能蓝牙直连** —— 部分早年车型不走常规随机数握手，程序自动识别后改用它们认的明文帧，手机号取登录账号；走新协议的车不受这条路影响，无需手动选协议族。
3. **先熄火再落锁** —— 走远落锁前先把车下电，确认车端已下电再上锁，落锁安静、不会鸣笛；也可切回锁后熄火。
4. **锁了就是真锁了** —— 落锁后按 1.5 / 4 / 12 / 30 秒复核车况，只认车端采样晚于下发的新鲜帧，确认没锁就补发一次；四档都过完仍明确未锁，「最近动作」里留一条「锁车失败」。
5. **阈值与灵敏度可调** —— 距离阈值手调；解锁灵敏度 2/4/6 帧，落锁延迟 2.5/4/6 秒。
6. **云端控车** —— 解锁、锁止、开后备箱、闪灯鸣笛、开/关空调；「远程上电」唤醒可行驶链路（踩刹车即可挂挡）、「一键熄火」下电。除车门解锁/上锁外，所有操作都弹确认。
7. **车况查看** —— 整车状态、门窗、胎压（车端原值 kPa）、温度、空调、里程能耗、健康自检，按本车实际支持项显示。
8. **后台不出"某天突然不解锁"** —— 扫描看门狗、解冻检测、建链退避与远场待机，加会话保鲜；后台自检改成判死才提醒，回前台自动复活。
9. **判不清就告诉你卡在哪** —— 「无感钥匙诊断」「接口诊断」各为独立页面，记录按自然日折叠、默认只展开今天，可一键复制当天记录；另有「后台检测」页按方向定位关卡。
10. **桌面小组件** —— 1×2 / 2×2 / 2×4 三种尺寸，每张卡片每格都能自选内容，可无限添加；可选「点卡片直接控车」，首次开启需手动输入确认文本以免误触。
11. **锁后提醒** —— 锁车后若车辆未熄火、车窗/天窗没关或后备箱还开着，会推一条通知，并在「最近动作」留一条黄色提醒；同时存在的多项合并成一条。
12. **控车通知** —— 解锁 / 上锁 / 熄火等动作通过系统通知栏即时提醒，可自定义铃声与震动，也可接入 MeoW 推到手表。
13. **主题色与应用图标** —— 六种预设主题色（含自定义 6 位色值）即时切换；应用图标黑/蓝/白三套任选。
14. **不与官方 App 顶登录** —— 沿用官方「手表钥匙」的独立授权通道（应用内出码、官方比亚迪 App 扫码确认），会话独立，可与官方手机 App 同时在线。

## 安装

```bash
hdc list targets
hdc install -r BYKEY-v1.6.9-unsigned.hap   # 未签名包，需先自行签名
```

> 未签名包装到真机需设备已开启开发者模式；长期使用请用自己的证书重新签名。
> 包名 `com.hmos.bykey` 的旧版（v1.5.0 及以后）可直接覆盖升级，无需卸载。

## 首次使用

1. 装好打开即进主界面（v1.5.1 起不再需要激活口令）
2. 应用内会显示一张二维码，用**官方比亚迪 App** 扫码并确认
3. 之后靠近车辆自动解锁、离开自动上锁（设置里可关）

官方 App 照常装着即可，两者登录互不影响。手表不装东西也能正常用。
